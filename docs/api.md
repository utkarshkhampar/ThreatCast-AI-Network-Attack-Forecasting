# ThreatCast — REST & WebSocket API Specification

## 1. API Architecture Overview
- **Base URL**: `http://localhost:8000/api/v1`
- **Interactive Documentation**: `http://localhost:8000/docs` (Swagger UI) & `/redoc` (ReDoc)
- **Protocol**: HTTP/1.1, HTTP/2, WebSocket (`ws://`)
- **Authentication**: Bearer Token in `Authorization: Bearer <JWT>` header
- **Content Type**: `application/json`

---

## 2. Authentication & Identity (`/auth`)

### `POST /auth/login`
Authenticates a user and issues an access JWT token.
- **Request (OAuth2 Form / JSON)**:
  ```json
  {
    "username": "analyst@threatcast.local",
    "password": "AnalystPassword123!"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6...",
    "token_type": "bearer",
    "expires_in": 28800,
    "user": {
      "id": "usr-01",
      "email": "analyst@threatcast.local",
      "role": "TIER_3_ANALYST"
    }
  }
  ```

## 4. Cyber Digital Twin & Simulation (`/simulations`)

### `POST /simulations/counterfactual`
Simulates the impact of hypothetical defender interventions against the forward attack trajectory.
- **Request**:
  ```json
  {
    "target_ip": "10.0.0.42",
    "horizon_steps": 5,
    "state_vector": [15.0, 120.0, 850.0, 250000.0, 45.0, 3.5, 0.85, 0.1, 12.0, 35.0, 0.05, 0.01, 0.8, 0.1, 25.0, 10.0]
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "target_ip": "10.0.0.42",
    "horizon_steps": 5,
    "scenarios": [
      {
        "scenario_id": "A_NO_ACTION",
        "action_type": "NONE",
        "projected_attack_probability": 0.94,
        "risk_reduction_percentage": 0.0
      },
      {
        "scenario_id": "B_ISOLATE_HOST",
        "action_type": "ISOLATE_ENDPOINT",
        "projected_attack_probability": 0.12,
        "risk_reduction_percentage": 87.2
      }
    ],
    "best_recommended_intervention": "B_ISOLATE_HOST"
  }
  ```

## 5. Controlled Active Defence (`/response`)

### `POST /response/execute`
Executes an authorization-gated defensive intervention.
- **Request**:
  ```json
  {
    "action_type": "ISOLATE_ENDPOINT",
    "target_ip": "10.0.0.42",
    "justification": "Mitigate projected lateral movement to database cluster",
    "mode": "DRY_RUN",
    "authorization_ticket": "AUTH-TK-84920"
  }
  ```
- **Response (200 OK)**:
  ```json
  {
    "execution_id": "ACT-84920-EXEC",
    "status": "SUCCESS",
    "mode": "DRY_RUN",
    "validation_results": {
      "is_whitelisted_cidr": true,
      "kill_switch_active": false,
      "rbac_approved": true
    },
    "simulated_effect": "Edge communication sever simulated; 0 packets dropped on physical NIC",
    "evidence_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
  }
  ```
